# 🎧 Spotify Clone (HTML, CSS, JavaScript)

A responsive Spotify-inspired music player built using pure HTML, CSS, and JavaScript. This project focuses on building a functional audio player with a clean UI and interactive features.

---

## 🚀 Features

- ▶️ Play / Pause songs  
- ⏭️ Next / Previous track  
- 📊 Progress bar with seek control  
- 🔊 Volume control  
- 📂 Playlist display  
- 🎧 Now playing section  
- 📱 Responsive design (mobile + desktop)

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript
